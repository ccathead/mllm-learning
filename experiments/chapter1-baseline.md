# 第1章：LLaVA 开放式视觉问答基线与错误分析

- 实验日期：2026-10-25；报告整理日期：2026-10-28。
- 状态：单图推理、30 题评测、人工评分、视觉特征观察及单样本遮挡实验完成。
- 任务：对 30 张 COCO 图片分别回答一个中文问题，输出开放式文本。
- 范围：使用已有模型做推理与评测；未进行训练、微调、loss 或梯度检查。

## 1. 本章结论

1. 已在单张 RTX 4090 D 上跑通 LLaVA 1.5 7B 的 FP16 推理，并建立可供后续比较的 30 题基线。30 条预测全部产生非空回答，记录的运行错误为 0。
2. 采用已填写的人工整数 0–2 分，总分 **38/60**，平均 **1.2667/2**，归一化得分 **63.33%**。其中 **15 题满分、8 题部分正确、7 题零分**。满分题比例为 **50.00%**；归一化得分不等于准确率。
3. 本批样本中，场景理解和空间关系的平均分分别为 1.75、1.60；物体识别、计数、文字读取各为 1.00。各类只有 1–9 题，这些数值用于描述本次样本，不能据此排定模型通用能力强弱。
4. 已观察到实际数据流：像素 `(1,3,336,336)` → 选取后的视觉特征 `(1,576,1024)` → projector 输出 `(1,576,4096)`。尚需沿真实 forward 验证这些特征如何进入语言模型。
5. 单张图片遮挡右下区域后，模型将工作服颜色从“蓝色”改答为“白色”。这支持“该输入改动伴随回答变化”；不足以单独证明具体注意区域、遮挡的因果机制或模型整体的幻觉率。

以上结论来自本地提供的原始输出、notebook 源码及人工评分。整理时没有重新运行 GPU 推理，也没有修改原始预测、标注或分数。

## 3. 数据与评分口径

数据来自本地 COCO 2017 验证集选图流程。选图清单含 30 个唯一图片 ID，`matched_categories` 均为 `person,bicycle`；具体提问仍覆盖颜色、物体、空间关系、计数、场景、动作及读字等任务。这是自建的小型中文图片问答集，不是官方 COCO VQA benchmark，也不是商品属性提取评测。

- 图片与题目：[data/my_vlm_test_set/](../data/my_vlm_test_set/)。每图一题，无本次训练/验证划分。
- 标注：[annotation_template.jsonl](../data/my_vlm_test_set/annotation_template.jsonl)。文件名虽含 template，内容已填写具体问题、参考答案和评分标准。
- 标注 SHA256：`3171b3aa9ca1ab708e8047cdaadc05989d769ef0da15f5f7bece9c3ab6389b0a`。
- 2 分：关键事实正确；1 分：部分正确或缺少关键要点；0 分：核心错误、未回答或无依据描述。具体按每题 `scoring_criteria` 及最终人工复核备注执行。
- 推理输入仅为图片和问题加统一指令；源码中参考答案、评分标准和备注未传给模型。
- 无独立多标注者一致性记录；本报告保留现有人工分数，未进行第二轮独立重评分。

30 题统一追加的指令为：

> 请仅根据图片中的可见信息回答问题。回答简洁明确；如果图片无法支持确定答案，请说明无法确定。不要猜测图片外的信息。

外层提示词由 `processor.apply_chat_template(..., add_generation_prompt=True)` 生成，实际结构为 `USER: <image>\n{该题问题}\n{统一指令} ASSISTANT:`。`config.json` 中的 `question` 是单图示例问题，不能代表全部评测题；逐题完整 prompt 以预测 JSONL 为准。

## 6. 张量观察与当前理解

证据：[tensor-trace.json](../outputs/w1-20261025T112208.803622Z/tensor-trace.json) 及 notebook 第 5、11 节保存的输出。

```text
单张图片
  → processor 后 pixel_values       (1, 3, 336, 336)
  → 选取后的视觉特征                (1, 576, 1024)
  → multi_modal_projector           (1, 576, 4096)
  → 语言模型的图文融合输入第2章待实际跟踪
```

该单图提示词的 `input_ids` / `attention_mask` 均为 `(1,623)`，其中图像 token 数为 576；语言模型 hidden size 为 4096。这里的 623 属于不附加评测统一指令的单图示例，不能用作全部 30 题的固定序列长度。

当前 notebook 在 `vision_feature_select_strategy == "default"` 时去掉视觉特征首 token，再执行 projector。可解释为：projector 将每个所选视觉向量从 1024 维映射到语言模型使用的 4096 维，本次视觉向量个数仍为 576。尚未记录融合后的 `inputs_embeds` 实测值，也未跟踪后续生成步的 KV cache。

源码位置为环境中 `transformers/models/llava/modeling_llava.py`，版本 4.57.1。原生 LLaVA 仓库用于后续对照，不能将其函数路径写成本次 HF 推理的实际调用链。

## 7. 单样本遮挡实验

原图：[000000008211.jpg](../data/my_vlm_test_set/images/000000008211.jpg)；改动图：[occluded.png](../outputs/w1-20261025T112208.803622Z/occluded.png)；记录：[occlusion-comparison.json](../outputs/w1-20261025T112208.803622Z/occlusion-comparison.json)。

- 输入尺寸：640 × 459；遮挡矩形为 `(320,229,640,459)`，灰色填充，覆盖约右下四分之一。
- 问题固定为“画面中有两个人坐在路边，他们穿着什么颜色的工作服？”；模型与生成参数固定。
- 原图回答：“在画面中，有两个人坐在路边，他们穿着蓝色的工作服。”
- 遮挡后回答：“在画面中，有两个人坐在路边，他们穿着白色的工作服。”

观察图像可见，矩形遮住两人衣服的大部分及部分周围场景，但顶部仍露出蓝色衣服。因此不能描述为“完全移除了衣服颜色信息”；回答变为白色的机制尚未验证。该题干还有前述坐姿预设问题。

此实验没有追加 30 题评测的统一指令，不能拿它判断加入“无法确定”指令后的拒答能力。遮挡比较只做了一张图片，没有等面积背景遮挡、重复实验或多样本统计，也没有可据此量化的幻觉率。

下一轮固定中性问题及提示词，对同一图片比较原图、关键区域遮挡、等面积背景遮挡，并保存遮挡坐标。若还要比较提示词，应另设实验，每次只改变一个因素。

## 8. 局限与第2章下一步

这份基线的用途是验证流程和支持后续受控比较。样本量小、类别不均衡，且选图集中包含 person 与 bicycle，不支持泛化为标准 benchmark 分数。数据是否出现在模型预训练中未核验，也没有建立独立的未知信息题组，因此不报告泛化能力或“不确定时编造比例”。

30 张图已用于观察错误和讨论后续策略，之后应将其视为开发对照集。第3章若用它选择提示词或裁剪策略，需要另留未参与选择的新图片做最终评估；划分时避免相同或高度相似图片跨集合。

建议按以下顺序进入第2章：

1. **处理器与 token（约 1–2 小时）**：沿当前安装版本的 `LlavaProcessor.__call__` 追踪图像占位符展开；打印不同问题下图像 token 数和完整序列长度。
2. **图文融合（约 2–3 小时）**：沿 `get_image_features`、`get_placeholder_mask` 和 `LlavaModel.forward` 查看 `inputs_embeds` 的形成；在语言模型入口临时记录形状，验证占位符位置的向量与 projector 输出对应。
3. **受控实验（约 1–2 小时）**：完成上述关键区域 / 背景遮挡对照，区分输入变化、提示词变化与推断的机制。
4. **实现对照（约 1–2 小时）**：对照原生 LLaVA 与所选版本 MiniGPT-4 的连接模块，记录源码版本、输入输出形状、连接方式和冻结策略；MiniGPT-4 先读源码。
5. **验收**：用实际张量和函数路径解释“576 个视觉向量如何进入 LLM”，把证据写入 `notes/`。之后进入第3章，同条件比较 Qwen2.5-VL，并提前固定评分边界与数据划分。
